# 내 웹북 저장소

이 저장소 하나가 웹북 한 권입니다. 글은 `book.json`에, 그림과 소리는 `assets` 폴더에 넣습니다.
다 채우면 저장소 주소를 웹북허브 작가 페이지(https://webbookhub.com/author/)에 제출합니다.

> 프로그램을 설치할 필요가 없습니다. GitHub 웹사이트 화면만으로 끝까지 할 수 있습니다.

---

## 1. 저장소 만들기 (처음 한 번)

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 웹북 템플릿 저장소 화면에서 초록색 **Use this template → Create a new repository**를 누릅니다.
3. **Repository name**에 책 이름을 영문으로 적습니다. 예: `forest-lantern`
4. **Private(비공개)**를 고릅니다. 공개로 만들면 누구나 원고와 그림을 볼 수 있습니다.
5. **Create repository**를 누릅니다.

## 2. 웹북허브 운영자 초대하기

비공개 저장소는 초대한 사람만 볼 수 있습니다. 운영자 계정을 초대해 주세요.

1. 내 저장소에서 **Settings → Collaborators → Add people**을 누릅니다.
2. `sionxai`를 찾아 초대합니다.

초대하면 운영자가 원고를 내려받아 검사하고, **고칠 곳이 있으면 직접 고쳐 드릴 수도 있습니다.** 웹북이 처음이라 어려운 부분(파일 이름, book.json 형식 등)은 운영자에게 맡기세요. 운영자가 고친 내용은 저장소 기록(커밋)에 그대로 남고, 무엇을 고쳤는지 작가 페이지의 내 제출에 알려 드립니다. 내용(이야기·그림)을 바꿔야 할 때는 먼저 물어봅니다.

## 3. 내용 채우기

### 폴더 구조

```text
내 저장소/
  book.json        ← 책 제목, 쪽마다 글, 어떤 그림을 쓸지
  assets/          ← 그림·영상·소리 파일
    cover.png      ← 표지
    forest.png     ← 1쪽 그림
  README.md        ← 이 안내 (지워도 됩니다)
  AGENTS.md        ← AI에게 줄 형식 규칙 (그대로 두세요)
```

이 밖의 파일이나 폴더(예: `pages/`, `index.html`, `.js`)가 있으면 검사에서 멈춥니다.

### 그림·소리 올리기

1. 저장소에서 `assets` 폴더를 엽니다.
2. **Add file → Upload files**를 누르고 파일을 끌어다 놓습니다.
3. 아래쪽 **Commit changes**를 누릅니다.

**파일 이름 규칙**
- 영문 소문자로 시작하고 영문 소문자·숫자·`-`·`_`만 씁니다. 예: `page-03.png`, `owl_sound.mp3`
- 한글, 띄어쓰기, 대문자는 쓰지 않습니다.
- 파일 이름(확장자 뺀 부분)이 곧 그 파일의 이름표입니다. `book.json`에서 `"imageAssetId": "page-03"`처럼 부릅니다.

**쓸 수 있는 파일**
- 그림: PNG, JPG, WebP (한 장 8MB 이하)
- 움직이는 그림: GIF, MP4, WebM, MOV (60초 이하)
- 소리: MP3, M4A, AAC, OGG, WAV

**크기 한도**
- GitHub 웹 업로드는 파일 하나에 25MB까지입니다.
- 파일 하나는 100MB 이하여야 합니다(GitHub 한도). 책 전체는 1GB까지 받습니다.
- 그림·영상·소리 한 개의 크기는 엔진 한도(그림 8MB, 영상 50MB·60초, 소리 3MB)를 따릅니다. 운영자 책과 같은 한도예요.

### 글 고치기 (`book.json`)

1. `book.json`을 누르고 오른쪽 위 연필(✏️) 아이콘을 누릅니다.
2. 예시 글을 내 이야기로 바꿉니다. 따옴표(`"`)와 쉼표(`,`)를 지우지 않게 조심하세요.
3. **Commit changes**를 누릅니다.

직접 고치기 어렵다면 **AI에게 맡기세요.** `AGENTS.md` 내용을 쓰는 AI(Claude, ChatGPT 등)에게 붙여 넣고, 내 원고와 그림 파일 이름을 알려 주며 "이 규칙대로 book.json을 만들어 줘"라고 하면 됩니다.

### 꼭 지킬 것

- **마지막 쪽 제작 표기:** `credits.author`에 작가 이름을, `credits.tools`에 실제로 쓴 도구를 적습니다(예: `"직접 그림"`, `"포토샵"`, `"Claude"`). 책 마지막 쪽에 표시됩니다.
- **권리:** 직접 만들었거나 사용 허락을 받은 글·그림·소리만 올립니다.
- **설명 글:** 그림마다 `imageAlt`에 그림을 설명하는 한 문장을 적습니다(앞을 못 보는 독자용).

## 4. 제출하기

1. 내 저장소 주소를 복사합니다. 예: `https://github.com/내아이디/forest-lantern`
2. [웹북허브 작가 페이지](https://webbookhub.com/author/)에 로그인해 **책 제출** 칸에 붙여 넣습니다.
   (작가 승인을 받은 계정만 제출할 수 있습니다. 아직이면 같은 페이지에서 작가 신청을 먼저 합니다.)

## 5. 제출 뒤에는

1. **검사:** 운영자가 저장소를 내려받아 형식·용량·참조를 자동으로 검사합니다.
2. **검토:** 운영자가 미리보기로 내용을 읽고, 고칠 점이 있으면 작가 페이지의 내 제출에 남깁니다.
3. **발행:** 검토를 통과한 책만 웹북허브에 올라갑니다. 제출했다고 바로 발행되지는 않습니다.

고친 뒤에는 같은 저장소에 다시 올리고 **다시 제출**하면 됩니다.
